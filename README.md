# 高考倒计时

一个包含桌面悬浮倒计时和网页版的小项目，倒计时精确到秒。

## 运行截图

![运行截图](屏幕截图%202026-09-20%20163314.png)

## 桌面版

双击 `启动桌面倒计时.bat`。倒计时会出现在桌面右上角，每秒更新；拖动可换位置，右键或右上角 `×` 可退出。
桌面组件使用透明背景，文字直接悬浮显示在桌面上，没有白色卡片。
它只显示在桌面层，不会悬浮到其它软件窗口上方；打开或使用其它软件时会自然被盖住。

## 网页版

双击 `index.html` 在浏览器中打开。右上角的齿轮按钮可以设置开考年份、日期和时间。

## 开机自启

- 双击 `设置开机自启.vbs`，会在 Windows 启动文件夹里创建「高考倒计时」快捷方式。
- 之后每次开机都会自动显示桌面倒计时。
- 如需取消，删除启动文件夹里的「高考倒计时」快捷方式即可。

## 修改默认考试时间

编辑 `config.json`：

```json
{
  "title": "2027 高考倒计时",
  "target": "2027-06-07 00:00:00"
}
```

`target` 表示开考日期和时间。网页版修改过设置后，会优先使用浏览器中保存的设置。
